## Football-data.org

Live operation requires an operator-owned registered application key and an appropriate subscription. [Provider terms](https://www.football-data.org/about) require confidential credentials, application-scoped use, fair use and visible attribution. They separately restrict referencing obtained data after cancellation and require graphics-owner permission for logos/photos. Provider responses are not covered by MIT and are not an open dataset. Keep keys server-side; do not publish cache dumps, response captures or subscription data. The app retains visible provider attribution; no live API calls are needed by tests.
